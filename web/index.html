Three ways
to get started.

Pick the method that fits your workflow. Every option delivers the full framework — no feature differences.

Via npm

Best for projects with a module bundler like Vite, Webpack or Parcel. Import it in your entry file.

Terminal
$ npm install kaple-css
// main.js
import 'kaple-css';

Via CDN

One line in your HTML head. No setup, no tooling — works instantly in any browser.

index.html
<link rel="stylesheet"
href="https://cdn.jsdelivr.net/npm/kaple-css/dist/kaple.min.css">
